# Company AI - Call Watcher & Transcriber

Система автоматического мониторинга аудиозаписей звонков, их транскрибации с помощью Whisper и сохранения результатов в базу данных PostgreSQL.

## Архитектура системы

```text
  incoming/ (WAV/MP3) 
         │
         ▼
     worker.py (Watchdog) 
         │
         ├───► local_transcribe.py (faster-whisper) ───► transcriptions/ (TXT)
         │
         ▼
    PostgreSQL (Docker, порт 5433)
```

1. **Watchdog (`worker.py`)**: Отслеживает папку `incoming/` на наличие новых аудиофайлов (`.mp3` или `.wav`).
2. **Локальный транскрибатор (`transcriber/local_transcribe.py`)**: Вызывается воркером через корневой `.venv` для расшифровки аудио с помощью модели `faster-whisper`. Текстовый результат сохраняется в папку `transcriptions/`.
3. **База данных PostgreSQL**: Сохраняет метаданные звонка (телефон, дату, время, уникальный ID) и полный распознанный текст в таблицу `call_transcriptions`.

---

## Структура папок

* `incoming/` — входящие аудиозаписи звонков (поддерживаются `.mp3` и `.wav`).
* `transcriptions/` — текстовые файлы с расшифровкой разговоров.
* `transcriber/` — исходный код транскрибатора (Whisper).
  * `local_transcribe.py` — скрипт локальной транскрибации.
* `worker.py` — фоновый воркер, отслеживающий появление новых файлов и координирующий весь процесс.
* `docker-compose.yml` — конфигурация Docker-контейнеров (PostgreSQL и n8n).

---

## Настройки подключения

* **PostgreSQL (в Docker)**:
  * Внешний порт: `5433` (изменен с `5432` для избежания конфликтов с локальной службой PostgreSQL на хосте).
  * База данных: `company`
  * Пользователь: `company_user`
  * Пароль: `company_password`
* **n8n (в Docker)**:
  * Доступен по адресу: `http://localhost:5678`

## Запуск проекта

### 1. Запуск инфраструктуры (Docker)
Запустите базу данных и n8n:
```powershell
docker compose up -d
```

Для остановки контейнеров выполните:
```powershell
docker compose down
```

### 2. Запуск воркера (Call Watcher)
Запустите фоновый скрипт отслеживания файлов через виртуальное окружение:
```powershell
.venv\Scripts\python worker.py
```

Воркер автоматически:
* При старте проверит папку `incoming/` на наличие уже лежащих там файлов и обработает их.
* Будет в реальном времени ожидать новые аудиозаписи.
* Проверит базу данных на наличие дубликатов по `unique_id`, чтобы не транскрибировать файлы повторно.
* Запишет результаты транскрипции в колонку `text` таблицы `call_transcriptions`.
